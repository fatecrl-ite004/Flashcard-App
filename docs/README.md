# Documentação do Projeto

Este repositório/diretório contém a documentação técnica, especificações e histórico de decisões do projeto.



## Estrutura de Pastas

* **`adr/`** — Architecture Decision Records. Registro das decisões de arquitetura tomadas ao longo do projeto e suas justificativas.
* **`architecture/`** — Diagramas, visões estruturais, fluxos de dados e especificações técnicas da arquitetura do sistema.
* **`research/`** — Documentos de pesquisa, benchmarks, estudos de viabilidade e referências técnicas consultadas.



## Arquivos Globais

* **`project-overview.md`** — Visão geral do projeto, escopo, objetivos de negócio e contexto de alto nível.
* **`system-specification.md`** — Especificação funcional e requisitos detalhados do sistema (regras de negócio/RN, RFs e RNFs).
