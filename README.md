## About the project

Flashcard App is a local-first flashcard application that uses FSRSv6 for spaced-repetition scheduling through [`ts-fsrs`](https://github.com/open-spaced-repetition/ts-fsrs).

The project aims to provide a simple study experience: create or import a deck, review the cards that are due and return later with the deck's progress and next reviews kept up to date. Advanced scheduling information will remain available to users who want to understand what happens behind the interface and want to tweak some parts of FSRS.

This application is being developed as a college final project for the Internet Systems program at Fatec Rubens Lara (Santos, São Paulo, Brazil). The project explores how thoughtful UI and UX can reduce the perceived complexity of spaced repetition while preserving transparency, offline access and essential functionality without paywalls.

## Current status
